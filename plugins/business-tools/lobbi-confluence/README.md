# Confluence Documentation Skill

Create, organize, and maintain technical documentation in Confluence with practical Jira integration patterns.

## What It Does

This skill provides guidance and templates for Confluence documentation workflows:

- **Document Templates** — TDD, ADR, API docs, runbooks, release notes, meeting notes, retrospectives
- **CQL Search Patterns** — Confluence Query Language examples for targeted content discovery
- **Jira Integration** — Smart links, issue macros, and linking patterns to connect docs to work
- **Best Practices** — Page organization, labeling strategy, review workflow, and maintenance

## Installation

```bash
ccpi add lobbi-confluence
```

## Triggers

The skill activates when you mention:
- "confluence doc", "write confluence page"
- "confluence template", "CQL search"
- "jira confluence", "technical design doc"
- "ADR", "runbook", "API documentation"

## Templates Included

| Template | Use Case |
|----------|----------|
| Technical Design Document | Feature/system design proposals |
| Architecture Decision Record | Recording architectural choices |
| API Documentation | Service API reference |
| Runbook | Operational procedures and incident response |
| Release Notes | Version release summaries |
| Meeting Notes | Meeting agendas, notes, and action items |
| Retrospective | Sprint retrospective facilitation |
