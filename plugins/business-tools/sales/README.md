# Sales Plugin

A comprehensive sales methodology plugin for Claude Code that helps you manage your entire sales cycle using proven frameworks.

## Features

- **Lead Qualification** — MEDDIC and BANT scoring frameworks
- **Pipeline Management** — Structured deal tracking with stage-based views
- **Proposal Generation** — Templates for compelling proposals and SOWs
- **Objection Handling** — LAER framework with common objection responses
- **Cold Outreach** — Personalized email sequences and call scripts
- **Competitive Positioning** — Battle cards and differentiation strategies
- **SPIN Selling** — Guided discovery conversation framework
- **Challenger Sale** — Teach, tailor, and take control methodology

## Installation

```bash
claude plugin install sales
```

## Usage

Activate the skill with phrases like:

- "Qualify this lead using MEDDIC"
- "Help me build a sales pipeline"
- "Write a proposal for [prospect]"
- "Handle the objection: too expensive"
- "Draft a cold email sequence"
- "Create a competitive battle card"

## Frameworks Included

| Framework | Best For |
|-----------|----------|
| MEDDIC | Enterprise deal qualification |
| SPIN Selling | Discovery conversations |
| Challenger Sale | Teaching and reframing |
| LAER | Objection handling |
