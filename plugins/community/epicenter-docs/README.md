# Epicenter Documentation Plugin

Documentation and development guide for [Epicenter](https://github.com/EpicenterHQ/epicenter) — an ecosystem of open-source, local-first apps that share a single folder of plain text and SQLite.

## Installation

```bash
/plugin install epicenter-docs@claude-code-plugins-plus
```

## Usage

```bash
/epicenter-docs
```

## Features

- Epicenter architecture and philosophy reference
- Whispering app documentation (transcription, AI transforms)
- Local-first development patterns with Svelte 5, Tauri, and Rust
- SQLite and plain-text storage conventions
- CRDT and offline-first data sync guidance
- AI model integration (OpenAI, Anthropic, local LLMs)

## About Epicenter

Epicenter is an ecosystem of open-source, local-first apps that store all data — notes, transcripts, chat histories — in a single folder of plain text and SQLite. Every tool shares this memory. Built with Rust, Svelte 5, and Tauri with 97% code sharing between desktop and web.
