# Data

**Data knowledge-work toolkit for Claude Code. Generate analysis reports, design data pipelines, and audit data quality using structured patterns.**

---

## Features

### Auto-Invoked Skills
- **Analysis Report**: Generate structured data analysis reports with executive summaries, key findings, and actionable recommendations
- **Pipeline Designer**: Design ETL/ELT pipelines with source mappings, transformation logic, DAG diagrams, and monitoring plans
- **Quality Auditor**: Audit data quality across six dimensions with scorecards and prioritized remediation plans

### Slash Commands
- `/analyze-data` - Generate a data analysis report
- `/design-pipeline` - Design a data pipeline specification
- `/audit-data-quality` - Audit data quality with a scorecard

---

## Installation

```bash
/plugin install data@claude-code-plugins
```

## Usage

### Analysis Report
```
Analyze the Q4 sales CSV and identify trends by region
```

### Pipeline Designer
```
Design an ETL pipeline to sync Stripe payments into our data warehouse
```

### Quality Auditor
```
Audit data quality of the users table before migration
```
