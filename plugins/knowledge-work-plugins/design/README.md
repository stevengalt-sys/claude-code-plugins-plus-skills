# Design

**Design knowledge-work toolkit for Claude Code. Create design system specs, conduct UX audits, and plan wireframes using structured patterns.**

---

## Features

### Auto-Invoked Skills
- **Design System Spec**: Create comprehensive design system specifications with tokens, component inventories, accessibility requirements, and usage guidelines
- **UX Audit**: Conduct usability evaluations against Nielsen's heuristics and WCAG 2.1 AA with severity-rated findings and remediation plans
- **Wireframe Planner**: Plan screen layouts with ASCII wireframes, content hierarchy, interaction annotations, and responsive adaptations

### Slash Commands
- `/create-design-system` - Create a design system specification
- `/ux-audit` - Conduct a UX audit
- `/plan-wireframe` - Plan a wireframe layout

---

## Installation

```bash
/plugin install design@claude-code-plugins
```

### Design System Spec
```
Create a design system for our B2B analytics dashboard
```

### UX Audit
```
Audit the UX of our checkout flow for accessibility and usability

### Wireframe Planner
```
Plan a wireframe for the user profile settings page
