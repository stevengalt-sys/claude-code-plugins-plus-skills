arguments:
  - name: target
    description: The screen, feature, or interface to audit
    required: true
---

Conduct a comprehensive UX audit of: $ARGUMENTS.target

Follow the design-ux-audit skill guidelines. Include:
1. Scorecard across usability, accessibility, consistency, and information architecture
2. Nielsen's heuristic evaluation with findings per heuristic
3. WCAG 2.1 AA accessibility findings
4. Consistency deviations
5. Prioritized remediation plan with effort and impact ratings

Maintain constructive tone. Highlight what works well alongside issues.
