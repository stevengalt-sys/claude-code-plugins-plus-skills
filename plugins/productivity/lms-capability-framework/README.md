# LMS Capability Framework

Enterprise Learning Management System capability framework for designing, building, and evaluating LMS platforms.

## Installation

```bash
/plugin install lms-capability-framework@claude-code-plugins-plus
```

## Features

Covers 8 functional modules:

1. **Course Management & Content Delivery** — courses, modules, lessons, learning paths, SCORM, video, PDF
2. **User & Role Management** — admin, instructor, manager, learner, author, compliance reviewer
3. **Learning Paths & Enrolment** — self-enrolment, assigned learning, cohort-based, prerequisites
4. **Assessment & Certification** — quizzes, question banks, grading, certificates, renewal tracking
5. **Reporting & Analytics** — completion rates, compliance, engagement metrics, role-based dashboards
6. **Integration Hub** — HRIS, SSO, Teams, Zoom, SharePoint, Power BI, REST API, webhooks
7. **Content Authoring** — in-platform authoring, SCORM/xAPI, Articulate/Rise/Storyline integration
8. **Administration & Governance** — content lifecycle, versioning, audit logs, compliance sign-off

Includes MVP vs Phase 2 roadmap and two implementation architecture options (Microsoft ecosystem or custom web platform).
