# Superpowers

Creative thinking superpowers for Claude Code. Unlock structured approaches to problem-solving that go beyond standard coding assistance.

## Skills

### Brainstorming
Generate diverse ideas using structured brainstorming techniques. Produces categorized ideas with feasibility ratings and identifies non-obvious connections.

**Triggers:** "brainstorm", "generate ideas", "think of ways to", "what are some approaches"

### First Principles
Break complex problems down to fundamental truths and rebuild solutions from scratch. Strips away assumptions to find root causes and novel solutions.

**Triggers:** "first principles", "break this down", "fundamental problem", "root cause", "why does this work"

### Reverse-Engineering Problems
Work backwards from desired outcomes to identify what needs to happen. Maps the path from goal to current state, surfacing hidden dependencies and blockers.

**Triggers:** "reverse engineer", "work backwards", "how would we get to", "what would need to be true"

### Red-Team Thinking
Challenge assumptions and find weaknesses by thinking like an adversary. Identifies failure modes, edge cases, and blind spots in designs and implementations.

**Triggers:** "red team", "find weaknesses", "what could go wrong", "devil's advocate", "stress test"

## Commands

| Command | Description |
|---------|-------------|
| `/brainstorm` | Run a structured brainstorming session |
| `/first-principles` | Analyze a problem from first principles |
| `/red-team` | Red-team an idea, design, or implementation |
