# Superpowers

Unlock advanced Claude Code capabilities with battle-tested patterns and workflows for multi-file refactoring, intelligent code generation, automated testing, and deep codebase analysis.

## Installation

```bash
/plugin marketplace add jeremylongshore/claude-code-plugins
/plugin install superpowers@claude-code-plugins-plus
```

## Features

### Skills
- **Superpowers** - Auto-activating skill that enhances Claude's coding capabilities with structured multi-file editing, smart test generation, and codebase-wide analysis patterns

### Commands
- `/superpower-refactor` - Perform intelligent multi-file refactoring with dependency tracking and rollback safety
- `/superpower-test` - Generate comprehensive test suites with edge cases, mocks, and coverage targets
- `/superpower-analyze` - Deep codebase analysis: architecture mapping, dependency graphs, and complexity hotspots

### Agents
- **Superpowers Agent** - Autonomous agent that combines refactoring, testing, and analysis into end-to-end code improvement workflows

## What Makes This Super

- **Multi-file awareness** - Tracks cross-file dependencies during refactors so nothing breaks
- **Smart test generation** - Analyzes code paths to generate tests that actually catch bugs
- **Architecture insights** - Maps your codebase structure and identifies complexity hotspots
- **Safe by default** - Always creates checkpoints before destructive operations
