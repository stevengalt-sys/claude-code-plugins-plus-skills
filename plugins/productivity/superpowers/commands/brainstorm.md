# Brainstorm

Run a structured brainstorming session on the topic provided by the user.

## Instructions

1. Ask the user what they want to brainstorm about if no topic was provided
2. Activate the brainstorming skill to guide the session
3. Frame the challenge as a "How might we..." question
4. Use at least 3 brainstorming techniques (Category Explosion, Inversion, Analogy Transfer, Constraint Removal)
5. Generate at least 15 ideas across multiple categories
6. Rate each idea on Impact, Effort, and Novelty
7. Identify connections and themes across ideas
8. Present the top 3-5 recommendations with concrete next steps

If the topic relates to the codebase, read relevant files first to ground ideas in reality.
