# First Principles

Analyze the given problem from first principles.

## Instructions

1. Ask the user what problem or topic to analyze if none was provided
2. Activate the first-principles skill
3. Clearly state the problem being analyzed
4. List and challenge every assumption — mark each as Keep, Discard, or Investigate
5. Identify the fundamental truths that remain
6. Build a ground-up solution from only those truths
7. Compare the ideal solution to the current approach
8. Provide a pragmatic path forward that bridges the gap

If analyzing a technical problem, read the relevant code to understand the current implementation before deconstructing assumptions.
